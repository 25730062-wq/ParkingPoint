서울시 공영주차장 모바일 홈 화면 (로우파이) — 수정본

[파일 구성]
project/
├─ index.html
├─ css/style.css
├─ js/app.js
├─ data/parking-lots.json
└─ asset/

[실행]
project 폴더에서 로컬 서버를 실행하세요.
  python -m http.server 8000
브라우저에서 http://localhost:8000 을 여세요.

index.html을 파일로 직접 열면 브라우저에 따라 GPS 위치 기능이 차단될 수 있습니다.
GPS 위치 확인은 브라우저의 사용자 허용이 필요하며 HTTPS 또는 localhost에서 사용하는 것이 안전합니다.

[이번 수정사항]
1. '바로 찾기'의 지역 버튼을 한 번 누르는 위치 기반 검색 버튼으로 변경.
   - 현재 GPS 위치를 획득하고, Mock Data에 저장된 주차장 좌표를 이용해 직선거리를 계산합니다.
   - 잔여 면수가 1면 이상인 주차장 가운데 가장 가까운 주차장 1곳을 홈에 표시합니다.
   - 현재 위치에서의 거리는 도로 주행거리/도보거리가 아닌 직선거리입니다.
2. 목적지 검색 하단에 '최근 검색' 추가.
   - 검색 실행 시 최대 5건까지 브라우저 LocalStorage에 저장합니다.
   - 최근 검색어를 누르면 즉시 다시 검색합니다.
   - 개별 삭제 및 전체 삭제를 지원합니다.

[데이터 및 범위]
주차장 이름, 좌표, 잔여 면수, 요금은 과제 시연용 가상(Mock) 데이터입니다.
지도, 예약, 마이페이지 등은 아직 구현하지 않았습니다.
디자인은 기존과 동일하게 흰색/회색/검은색만 사용합니다.
