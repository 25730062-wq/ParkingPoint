#### v0.6 최종 화면·동작 요약 (`ParkingPoint_1123.zip` 기준)

- 공통 헤더: 텍스트 P 아이콘 대신 업로드한 PNG 로고를 사용합니다. 주요 화면의 로그인/로그아웃 및 하단 홈·탐색·마이 구조는 보존합니다.
- 홈: 기존 최대 2곳 대신 최대 6곳을 보여줍니다. 위치가 있으면 3km·5km·근거리 순으로 후보를 채우고, 없으면 서울 전체 모의 통계 순으로 선정합니다. 방문 횟수는 실제 이용 통계가 아닌 시연 자료입니다.
- 지도: 297개 상세/예약 대상은 밝은 P 마커, 186개 지도 전용 대상은 어두운 P 마커로 구분합니다. 마커 팝업에서는 왼쪽에 `예약 가능 / 전체 면수` 및 `기본 요금` 라벨, 오른쪽에 수평 면수 `N/M` 및 시간당이 아닌 `N분당 금액` 형식의 기본 요금을 배치합니다. 이 수치는 실시간 입차/출차 정보가 아닙니다.
- 상세: 상단 주차장 사진, 명칭·주소, 전체 주차면과 기본 요금, 평일 운영시간, 접을 수 있는 토요일·공휴일 시간, 예약 진입으로 구성합니다. 최종본에는 `주차장 상세 정보` 문구가 없고 할인 안내 및 `detailNote`의 출력이 숨겨집니다.
- 예약: 주차면 선택 후 영수증 모양의 `결제 내역`·예상 합계가 나타나고, 다음 단계에는 예약 요약(주차면, 이용 시간, 예상 요금)이 표시됩니다. 예약자 입력에서는 이름 칸이 빠지고 연락처 및 차량번호만 필수입니다. 로그인 닉네임 등 기존 세션 값이 예약자 이름에 사용될 수 있습니다.
- 예약 완료: 예약번호, 주차장, 주차면, 이용 시간, 예약 금액과 상태를 영수증 형태로 표시하고 마이페이지로 이동합니다.
- 마이페이지: 날짜/정렬 필드는 상시 노출되고 주소 검색은 접을 수 있습니다. `이용 중`·`완료·취소` 상태를 누르면 선택 필터가 적용되며 다시 누르면 전체로 돌아갑니다. 예약 카드를 왼쪽으로 스와이프하면 별도의 취소 확인창이 열리도록 이벤트가 추가되었습니다.
- 인증: 별도 체험 로그인 버튼을 삭제했습니다. 로그인 화면의 회원가입 링크는 계정 찾기/비밀번호 재설정과 같은 줄 오른쪽에 배치합니다. 새 회원가입은 영문·숫자·특수문자 포함 8자 이상 비밀번호를 검사합니다.
- 이미지: 이전 샘플 JPG 4개가 ZIP에 남아 있지만 상세 및 마이페이지 예약 카드의 최신 표시 경로는 WebP 40장 풀입니다. 동일 주차장명에는 동일 이미지가 매핑되는 결정적 의사 무작위 방식이며, 서로 다른 이름이 같은 사진으로 매핑될 수도 있습니다. 사진은 실제 시설 촬영·검증 사진으로 간주하지 않습니다.

주의: 11월 23일 2단계에서 홈 모의 통계 안내 문단에 `hidden`이 부여된 상태가 11월 23일 최종본에도 유지됩니다. 11월 23일 작업 중에는 다수 화면의 하단 시연 안내 문구를 삭제했습니다. 화면의 문구 축소로 실제 실시간 잔여 주차면·예약·결제가 구현된 것은 아닙니다. 이용자 오인 가능성을 별도 테스트에서 확인해야 합니다.

정적 검증 범위: 이전 v0.5 ZIP과 11월 23일 단계별 작업본의 파일 추가·삭제·변경을 비교했습니다. 최종 ZIP 안의 이미지 파일 40개와 JS 이미지 선택·연결 코드를 대조했으며, 모바일 기기 조작·브라우저 위치 권한·카카오 SDK 응답·취소 스와이프·실제 예약 테스트까지 수행한 것은 아닙니다.

#### 5-2. 데이터 역할 분담 (API 연동판 기준)

| 구분 | JSON 주차장 | 카카오 API 주차장 |
|---|---|---|
| 출처 표기 | J | A |
| 제공 정보 | 이름, 주소, 좌표, 전체 주차면, 운영시간, 요금 | 장소명, 주소, 좌표 |
| 예약 시연 | 가능 | 위치 정보 표시 위주 |
| 표시 위치 | 지도 핀, 주변 주차장 목록 | 지도 핀, 주변 주차장 목록 |

- 주변 주차장 목록에는 각 주차장의 데이터 출처(J = JSON / A = API)를 함께 표시합니다.
- 카카오 API 사용 시 GitHub Pages 배포 도메인을 카카오 개발자 콘솔의 허용 도메인에 등록해야 합니다. API 키는 문서에 기재하지 않습니다.

#### 5-3. 주요 데이터 필드 (JSON)

주차장명, 도로명/지번주소, 위도·경도, 전체 주차면, 운영일·운영시간, 기본/추가 요금 등.

#### 5-4. 데이터 제한

- 실시간 잔여 주차면, 실제 예약 가능 여부, 결제 승인·실제 예약 처리는 제공되지 않습니다.
- 값이 없는 요금·운영정보는 실제 사실로 추정하지 않습니다.
- 실제 검색 노출 건수는 `parking-data.js`의 변환·필터 조건에 따라 483건과 다를 수 있습니다.
- 원본 JSON이 바뀌면 `parking-data.js`를 다시 생성해야 합니다.

#### 5-5. v0.5 통합 버전의 지도·저장소 적용 상태

- `pages/map.html`에는 카카오맵 JavaScript SDK 로더가 포함되어 있고, `js/app.js`에는 SDK 성공 시 실제 지도를, 실패 시 SVG 시연 지도를 활용하는 처리 경로가 있습니다. 카카오 API의 실제 성공이나 GitHub Pages 도메인 인증은 별도 검증 대상입니다.
- 공공데이터에 등록된 주차장을 기준으로 시연용 상세·예약을 제한합니다. 카카오 장소 검색 등 외부 장소 정보는 등록 주차장의 시연 예약 정보와 구별합니다.
- 홈 위치 선택값은 `sessionStorage`의 `pp:location-choice:v1`, 좌표는 `pp:position:v3`에 저장하도록 작성되어 있습니다. 위치 권한 선택은 일반적으로 같은 탭 동안 유지됩니다.
- 이전 디자인 문서의 J(원본 JSON) / A(카카오 API) 출처 표시는 자료상 역할 구분으로 보존하며, 실제 노출·예약 경로는 최종 코드를 우선합니다.
- 서버 기반 인증, 실시간 잔여 면수, 실제 예약·결제 동기화는 제공하지 않으며, API 키는 문서에 기록하지 않습니다.
